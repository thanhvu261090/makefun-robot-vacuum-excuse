The funniest one-line excuse a robot vacuum gives for missing a spot.

> "I didn't miss that spot — my lidar classified it as emotional support dust, and my bumper signed a peace treaty with it."

## How it works

`main.py` holds the entry line as a constant, checks it against the kit's gate (UTF-8 text, 1–140 characters, not only whitespace, a single line with no control characters or padding), and writes it to `/output/entry.txt` when run with `python3 main.py`.
